# Как Shopmark подбирает покупки

Автопомощник оценивает механику предметов и сверяет её с фактическими покупками на текущем герое. Каталог пользовательских сборок используется отдельно.

## Статистика покупок

`npm run sync:purchase-flow` получает данные Deadlock API по 44 героям за текущий патч. Выборка включает обычные рейтинговые матчи со средним рангом обеих команд от Phantom I. Для каждого героя хранятся частота покупок среди дошедших до фазы, средний нетворс при покупке, сглаженное отклонение винрейта и частые переходы между фазами. Фазы охватывают 0–9, 9–20, 20–30 и 30+ минут. Скорректированный винрейт влияет на близкие оценки и сам по себе не доказывает полезность предмета. После смены даты патча сборщик использует статистику только после обновления снимка. [Deadlock API](https://api.deadlock-api.com/docs).

## Порядок и контрпредметы

Для восьми будущих шагов учитываются компоненты, накопление, фаза игры и личный нетворс. Обычная очередь не возвращается к более низким ценовым уровням. Доплата за рецепт может быть меньше полной цены предыдущей вещи. Соперники с большим видимым нетворсом повышают приоритет подходящих контрмеханик среди предметов текущего этапа.

Игровые данные покрывают 44 героя и 173 предмета. Классифицированы 170 структурированных условных свойств у 90 вещей. Фактическое здоровье читается из HUD. Для условий без наблюдения, например попадания в голову или парирования, применяется консервативная оценка. Веса полезности остаются эвристикой. Текущие покупки врагов и полученный в драке урон HUD-адаптер пока не передаёт.

Вкладка SHOPMARK показывает отдельную очередь в магазине и реальные купленные предметы. Перестроение очереди меняет только советы. Покупки выполняются игроком через штатные карточки.
