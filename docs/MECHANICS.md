# Самостоятельный подбор: исправленное требование

Авторские сборки и их тексты не участвуют в решениях автоматического режима. Каталог сообщества остаётся отдельной функцией.

Новый модуль `src/decision.js` оценивает все доступные предметы по проверенным механикам: польза своему герою, условия срабатывания, ответы на механики каждого противника, личное соотношение нетворса, уже закрытые потребности, компоненты, доплата и время накопления. Он возвращает новый порядок и списки добавленных/исключённых шагов. Исключение из плана не означает продажу купленной вещи.

Профиль героя содержит возможности применять эффекты, полезные направления усиления и потенциальные угрозы. Предмет содержит эффекты, условия, контрмеханики и источник проверки. Открытые покупки противника уточняют угрозу отдельно от предположений по герою. Командная сумма душ не подменяет личное сравнение.

Статус: вычислительное ядро и синтетические проверки добавлены. Оно **ещё не подключено к установленной 0.4 beta**. Нужны проверенная база механик всех предметов/героев, корректная оценка нелинейных взаимодействий и игровая проверка новой очереди. Текущий HUD-адаптер не передаёт покупки противников: поддержка этого поля в ядре не означает, что эти покупки уже читаются из игры. Предыдущая 0.4 использует авторскую основу и не соответствует уточнённому требованию.
