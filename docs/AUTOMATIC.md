# Автоматический режим: ветка разработки

Реализованы адаптер HUD, вычисление рекомендаций и отдельный переключатель в магазине. Это **незавершённая интеграция**, не новый публичный релиз. Проверки на фикстурах не подтверждают работу в матче.

## Что делает код

- Один независимый сервис под `Hud` загружается из уже изменяемой карточки магазина. `base_hud`, верхняя панель и основной магазин не заменяются дополнительными копиями.
- В обычной сборке режим выключен. Переключатель включает чтение раз в секунду; выключение очищает следующую рекомендацию. Выбор сборки передаётся кнопкой «Для автопомощника» в браузере.
- Адаптер читает локальную отметку `LocalPlayer`, имя героя, души команд и игроков, время матча, текущую валюту и признаки владения предметами. Маршруты взяты из установленных XML build 6839. Состав команд берётся из верхней панели; никнеймы не читаются.
- Инвентарь определяется по известным классам иконок или подтверждённым `owned` карточкам с проверкой количества активных слотов. Если предмет нельзя однозначно определить, очередь приостанавливается. Пустой инвентарь не подставляется вместо неизвестного.
- Купленное и поглощённые рецептом компоненты исключаются. Рассчитывается оставшаяся цена улучшения. Продажа позволяет снова рассмотреть предмет.
- Предметы в собственной очереди меняют порядок по доступности, отставанию и открытым героям соперника. На штатной карточке следующий предмет получает коралловый контур. Покупки и игровое управление не выполняются.
- Иллюстрации используют `s2r://panorama/images/items/...` из игры. На build 6839 все 173 пути сопоставлены с установленным архивом. Изображения не генерируются и не скачиваются во время матча.

## Границы оценки

Положение команды оценивается по разнице открытых душ, с нейтральной зоной 12%. «Линия по душам» — сравнение среднего дохода отмеченных игрой участников линии после второй минуты; последнее наблюдение до восьмой минуты сохраняется. Это экономическая оценка, не утверждение о разрушенных объектах или качестве всех разменов.

Подсказка под соперника основана на его герое и открытом доходе. Имя героя само по себе не доказывает, какой урон получает игрок. Поэтому совет явно описывает условие применения. Отчёт о смерти, фактическое лечение врага, кулдауны и скрытые действия пока не читаются. Для героя без описанного правила остаётся базовый план сборки.

## Результаты проверки 1 ноября 2026

- Модульные проверки охватывают смену героя/матча, включение/выключение, устаревшие данные, покупки, продажу, компоненты, доплату, неизвестный инвентарь, состав команд, зрителя и экономику. Используются небольшие фикстуры по реальным маршрутам XML; это не запись успешного матча.
- Ранее запущенный локальный пробник действительно прошёл из карточки магазина до общего `Hud` и прочитал штатные подписи времени и валюты. Полный игровой цикл не подтверждён.
- Два перехода на установленную `hero_testing` завершились native-сбоем `0xc0000005` в `client.dll`. Причина не установлена; нельзя приписывать сбой другому моду без изолированной проверки.
- Диагностический VPK удалён из установки, восстановлен исходный артефакт 0.3.0 с проверкой SHA-256. По просьбе пользователя дальнейшие действия не занимают рабочие окна ПК.

## До выпуска

Нужно подтвердить покупки вне выбранной сборки, продажу/улучшения, смену героя, переподключение, отсутствие устаревших данных и чтение обоих составов в работающем клиенте. Также нужны проверка положения/иконок и профиль времени кадра при включённом помощнике. До этого `runtimeTested` остаётся `false`; релиз полного автоматического помощника не выпускается.

`npm run build -- --probe` создаёт только локальную диагностическую сборку: она включает режим и пишет небольшие снимки в консоль. Такой артефакт не предназначен для распространения. Обычная сборка не включает пробник.
