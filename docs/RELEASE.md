# Перед публичным выпуском

1. Обновить roster при необходимости и сверить Steam account ID с источниками; не брать имена из заголовков сборок.
2. Выполнить `npm run sync`, проверить `data/coverage.json`, `snapshot.failures`, дату патча и статусы обзора. Проверить новый раздел Items вручную, если `reviewed=false`.
3. `npm test`, `npm run test:ui`, `npm run build`, `npm run doctor`. Сохранить manifest и отчёт рядом с архивом.
4. В отдельном профиле менеджера проверить чистую игру, затем Shopmark: запуск, магазин, все вкладки, предметы без изменений/с усилением/ослаблением/переработкой, поиск сборки, штатное применение, другой герой, перезапуск.
5. Проверить 720p/1080p/1440p, 16:9/21:9 и масштаб UI; отсутствие наложений на цены, активные/усиленные/испорченные предметы и подсказки. Проверить русский и английский клиент.
6. Проверить сторонние моды из матрицы совместимости и удаление Shopmark. Зафиксировать список проверенных версий. Только после проверки поставить `runtimeTested=true` в итоговом manifest и обновить README.
7. Снять настоящие игровые скриншоты. Запустить `powershell -File tools/package.ps1`. Архив содержит единственный VPK в корне.
8. После согласования итогового результата заполнить карточку GameBanana. Свериться с текущими правилами площадки и каталогом Deadlock Mod Manager; публикация в одном сервисе сама по себе не гарантирует включение в другой.

В первой версии не обещать полную совместимость, автоматическое обновление в игре, подтверждённую метовость всех сборок, автоматическое применение или покупку предметов.
