# Shopmark 0.2

Подборки для героя и ранга матчей, без фильтра по про автору. Чёрно-коралловая тема, цветные штатные изображения, отметки баланса и объяснения.

Минимум 20 ranked-матчей после даты выбранного патча. Ранг — средний badge обеих команд. При недостатке данных интерфейс сообщает об этом. Источник сборки фиксируется в начале матча, фактические покупки могут отличаться.

Установка: отключить Shopmark 0.1, импортировать VPK из релиза 0.2 в менеджер, перезапустить игру. Конфликтующие ресурсы перечислены в README. Игровая проверка 0.2 не завершена. На GameBanana и в каталог менеджера ещё не отправлено.
