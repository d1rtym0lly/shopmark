# Shopmark — текст будущей карточки

**Категория:** Deadlock / GUI / Shop & Builds (окончательная категория выбирается в актуальном каталоге).

Сборки разных про авторов в браузере игры. Предметы показывают, что поменял последний проверенный патч: ↑ усилили, ↓ ослабили, = не трогали. Смешанные и ещё не проверенные изменения обозначены отдельно.

Подборки для всех доступных героев, подписи реальных авторов, дата обновления и честная отметка недостаточной статистики. Лента патчей и причины изменения предметов. Данные обновляются перед выпуском VPK; во время игры сетевых запросов нет.

**Установка:** импортировать VPK через Add Local Mod в Deadlock Mod Manager. Открыть браузер сборок нужного героя, выбрать того же героя в Shopmark, найти сборку и нажать штатную кнопку «Использовать».

**Конфликты:** замены `citadel_ui_build_selector`, `citadel_shop_mod_view`, `citadel_shop_mod_view_favorites`. Требуется объединённая версия для модов, которые правят эти же ресурсы.

**Текущий статус:** альфа, игровая проверка не завершена. Эта карточка — черновик; загрузка на площадки не выполнена. Не выдавать веб-предпросмотр за скриншот игрового клиента.
