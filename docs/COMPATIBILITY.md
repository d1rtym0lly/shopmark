# Проверка совместимости

| Проверка | Состояние |
|---|---|
| Компиляция 7 ресурсов Panorama | Пройдена, CS2 resourcecompiler |
| Упаковка VPK v1 и повторная проверка всех CRC | Пройдена |
| Native layout hashes для Deadlock 6839 | Совпадают |
| Пересечения с VPK в текущих найденных addons | Не обнаружены |
| Передача ID в штатный поиск, выбор сборки | Реализована, нужна проверка в игре |
| Стрелки в магазине и избранных сборках | Скомпилированы, нужна проверка отображения в игре |
| Загрузка, перезагрузка, смена героя | Нужна проверка в игре |
| 16:9, 16:10, 21:9, масштаб UI | Нужна проверка Panorama; веб-предпросмотр проверен отдельно |
| Совместная работа с другими HUD/shop-модами | По совпадению ресурсов; ручная проверка сочетаний |
| Импорт/удаление через Deadlock Mod Manager | Пакет подготовлен, нужен тест менеджера |
| Одобрение GameBanana/каталога менеджера | Не запрашивалось |

На этой машине тестовый запуск игры завершился без подключения Steam API. Успешная компиляция не заменяет проверку игрового UI.

Отчёт конкретной сборки создаётся `npm run doctor` в `dist/compatibility-report.json`. Он сканирует обнаруженные VPK и сравнивает три исходных layout-файла. Он не анализирует семантические конфликты JS/CSS и не знает о неактивных профилях или произвольных монтированиях, которые не удалось определить.

При обновлении игры сначала повторить build/doctor и игровую проверку. Если изменилась структура XML, сборщик останавливается на отсутствующем anchor. Если структура сохранилась, это всё ещё не доказательство работоспособности: native callbacks и размеры могут измениться.
