# Проверка совместимости 0.4 beta

| Проверка | Состояние |
|---|---|
| Компиляция 15 ресурсов Panorama | Пройдена, CS2 resourcecompiler |
| Упаковка VPK v1 и повторная проверка всех CRC | Пройдена |
| Native layout hashes для Deadlock 6839 | Совпадают |
| Пересечения с VPK в текущих найденных addons | Не обнаружены |
| Источник инвентаря и автоматическая очередь | Проверены покупка, улучшение, отмена и продажа при закрытом магазине |
| Команды, кошелёк, герой, русские сокращения душ | Прочитаны в работающем локальном клиенте |
| Компактная карточка следующего предмета | Загружена движком, выбор стороны и режима иконки проверены |
| Преимущество / результат линии ручного помощника | 9 комбинаций через native DropDownSelectionChanged без вылета клиента |
| Передача ID в штатный поиск, выбор сборки | Исправлен жизненный цикл native-поля; нужны дополнительные игровые сценарии |
| Стрелки в магазине и избранных сборках | Скомпилированы, нужна проверка отображения в игре |
| Загрузка и смена героя | Проверены Infernus → Haze в локальном клиенте |
| Полный матч и переподключение | Ещё не проверены |
| 16:9, 16:10, 21:9, масштаб UI | Нужна проверка Panorama; веб-предпросмотр проверен отдельно |
| Установленные HUD-моды | Автоматическая очередь работает в локальном сценарии; все сочетания не проверены |
| Влияние на время кадра | Чтение раз в секунду; профиль времени кадра ещё нужен |
| Импорт/удаление через Deadlock Mod Manager | Пакет подготовлен, нужен тест менеджера |
| Одобрение GameBanana/каталога менеджера | Не запрашивалось |

Стенд работает с подключённым Steam API на отдельном рабочем столе без переключения пользовательских окон. Успешный локальный сценарий не заменяет полный матч: поэтому бета имеет `runtimeTested: false`. [Проверенные сценарии](AUTOMATIC.md).

Отчёт конкретной сборки создаётся `npm run doctor` в `dist/compatibility-report.json`. Он сканирует обнаруженные VPK и сравнивает три исходных layout-файла. Он не анализирует семантические конфликты JS/CSS и не знает о неактивных профилях или произвольных монтированиях, которые не удалось определить.

При обновлении игры сначала повторить build/doctor и игровую проверку. Если изменилась структура XML, сборщик останавливается на отсутствующем anchor. Если структура сохранилась, это всё ещё не доказательство работоспособности: native callbacks и размеры могут измениться.
